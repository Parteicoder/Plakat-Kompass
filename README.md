# Plakat Kompass

**Nie wieder Plakate suchen.**

Kostenlos für euch. Kein Server, keine Anmeldung, kein Stress.

🔗 **Webseite:** [plakat-kompass.de](https://plakat-kompass.de)

## Das Problem

Wahl vorbei, eine Woche zum Abhängen, und keiner weiß mehr, wo die letzten dreißig Plakate hängen.

## So funktioniert's

Knopf drücken, Foto machen, fertig. Der Standort sitzt auf wenige Meter genau, das Plakat liegt sofort auf der Karte.

## Funktionen

- Jedes Plakat wiederfinden und navigieren
- Countdown bis zur Abnahmefrist mit Benachrichtigung
- Status in zwei Sekunden erfassen (OK, Kaputt, Fehlt)
- Teamabgleich ohne Internet
- Automatische Berichte mit Fotos für Behörden

## Ersparnis

Von 4.200 € Verlust auf 600 € — 3.600 € Ersparnis pro Wahl durch Reduktion des Schwunds von 7 % auf ca. 1 %.
